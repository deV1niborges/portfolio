# Portfólio — Vinicius Borges

Portfólio pessoal em HTML, CSS e JavaScript puro, com Three.js e GSAP.

## Estrutura

- Intro 3D holográfica com Three.js
- Destaque de Minas Gerais e marcador de localização
- Tela de boas-vindas animada com GSAP
- Hero
- Sobre
- Tech Stack
- Projetos
- Formação
- Cursos e certificações
- Contato
- Navegação responsiva, progresso da página e microinterações

## Tecnologias do próprio portfólio

- HTML5
- CSS3
- JavaScript ES Modules
- Three.js
- GSAP
- GSAP ScrollTrigger

## Como rodar

O projeto usa módulos ES, então abra com um servidor local. No VS Code, a forma mais simples é usar **Live Server** e abrir `index.html`.

Não abra apenas dando duplo clique no arquivo (`file://`), porque imports de módulos e requisições podem ser bloqueados pelo navegador.
